# banking-analytics-project

## Overview

End-to-end banking analytics project using SQL Server and Power BI.

The project covers:

- Data profiling
- Data cleaning
- Data warehouse design
- SQL transformations
- Data modeling
- DAX analysis
- Power BI dashboard
- Business insights

## Business Questions

1. Does transaction volume/value increase at certain times of the year?
2. Which transaction type occurs most frequently?
3. Which transaction type has the highest total transaction value?
4. Which account type has the highest transaction activity?
5. Which account type has the highest total transaction value?
6. How many customers are there in each customer type?
7. Which customer type takes the most loans?
8. How do loan values compare with deposits?
9. Which branches have the highest transaction activity?

## Data Warehouse Layers

- **Bronze:** Raw source data
- **Silver:** Cleaned and standardized data
- **Gold:** Analytical model for reporting
